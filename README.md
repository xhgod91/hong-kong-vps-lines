## 原生 IP、双 ISP、机房 IP，差的不只是标签

普通香港 VPS 给的 IP 在数据库里归属于数据中心。拿它建站没问题，一旦碰到会校验“你是不是本地用户”的平台，限制马上就来：

- **Cityline 票务**：非香港本地 IP 无法购票，这是硬门槛，没有绕过的办法
- **TVB 直播、Netflix 港区、Disney+、YouTube Premium**：按 IP 归属地做校验，机房段经常直接被拦
- **eBay、Amazon 香港店铺、Shopee**：机房 IP 容易触发风控，账号状态不稳定
- **TikTok 香港账号**：本地住宅 IP 下的账号存活率和自然流量表现更好

原生 IP 指的是 IP 由香港本地运营商真实分配，数据库里标成香港住宅或本地 ISP。双 ISP 住宅 IP 再进一步：同一个 IP 同时被两家运营商登记为家庭宽带用户。用生活化的说法，原生 IP 像是拿了香港身份证，双 ISP 则是身份证之外还揣着两张不同运营商开的家庭宽带账单，平台风控看到的就是一个普通香港住家用户。

需要先降低期待的是：具体解锁状态受平台风控策略影响，今天能看 TVB 不等于三个月后一定还能看，整个行业都是这样。买住宅 IP 买的是“更接近真实用户”的概率，不是永久的通行证。
